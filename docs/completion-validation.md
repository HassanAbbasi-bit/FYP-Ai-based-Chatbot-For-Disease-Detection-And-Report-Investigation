Twelve flows passed, zero page errors: registration/dashboard; saved profile/consent after refresh; saved demo chat/message feedback; reviewed extraction and durable synthetic result; authenticated PDF download; result feedback and outdated revision; bound report conversation; history filters/selection/dedicated comparison; mobile 390px no document overflow and keyboard-labelled input focus; delete-all clears mounted chat; logout/new-account profile/report isolation; password-confirmed account deletion.

Initial full-run failures were addressed rather than counted as passes: parallel test databases exhausted C: minimum free space; isolated temporary files moved to an owned ignored F: test directory and tests serialized. Browser harness selectors were corrected for intentionally retained hidden chat and mobile history disclosure. Built-in browser/repl tools failed to initialize, so the installed browser was used through the installed Playwright package; no browser download or private existing browser profile was used.

Adapter tests are synthetic contract/transport checks, not live FastAPI inference or clinical evaluation. Live service origin/key/model/fallback, corrected-analysis/context, citations, real matching/conversions, summary, approved urgency rules and provider privacy/cancellation remain external verification needs. GitHub Actions configuration is added; its hosted run is not claimed before CI actually reports success. Nothing is deployed or automatically merged.
